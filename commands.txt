TANGent command reference
========================

Run the app
-----------

Run in MySQL mode from the repo root:
cmd /c ".\mvnw.cmd spring-boot:run"

Run in dev mode with the in-memory H2 database:
cmd /c ".\mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=dev"

Run the bash startup script when using a bash shell:
./run.sh

Stop/check the server
---------------------

Check whether anything is listening on port 8080:
Get-NetTCPConnection -LocalPort 8080 -State Listen -ErrorAction SilentlyContinue | Select-Object -First 3 -Property LocalAddress,LocalPort,OwningProcess | Format-Table

MySQL setup and access
----------------------

PowerShell-safe schema seed command:
Get-Content .\database\tangent_schema_seed.sql | & "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p

Alternative seed command if using a shell that supports input redirection:
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p < .\database\tangent_schema_seed.sql

Temporarily add MySQL to PATH for the current PowerShell session:
$env:Path += ";C:\Program Files\MySQL\MySQL Server 8.0\bin"

Verify the database connection works:
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p -D tangent_db -e "SELECT 1 AS db_ok;"

App/API verification
--------------------

Log in and get an auth token:
$auth = Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/auth -ContentType "application/json" -Body '{"mode":"login","email":"student@tangent.local","password":"training123"}'
$headers = @{ Authorization = "Bearer $($auth.data.token)" }

Read bootstrap data:
$before = Invoke-RestMethod -Headers $headers -Uri http://localhost:8080/api/app/bootstrap

Update asset 1:
Invoke-RestMethod -Method Put -Headers $headers -Uri http://localhost:8080/api/app/assets/1 -ContentType "application/json" -Body '{"value":240000,"income":8300}'

Read bootstrap data again:
$after = Invoke-RestMethod -Headers $headers -Uri http://localhost:8080/api/app/bootstrap

One-shot end-to-end asset update verification:
$auth = Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/auth -ContentType 'application/json' -Body '{"mode":"login","email":"student@tangent.local","password":"training123"}'; $token = $auth.data.token; $headers = @{ Authorization = "Bearer $token" }; $before = Invoke-RestMethod -Headers $headers -Uri http://localhost:8080/api/app/bootstrap; $class = $before.data.portfolioClasses | Where-Object { $_.items.Count -gt 0 } | Select-Object -First 1; $asset = $class.items[0]; $newValue = [decimal]$asset.value + 1234; $newIncome = [decimal]$asset.income + 56; $body = @{ value = $newValue; income = $newIncome } | ConvertTo-Json; Invoke-RestMethod -Method Put -Headers $headers -Uri "http://localhost:8080/api/app/assets/$($asset.id)" -ContentType 'application/json' -Body $body | Out-Null; $after = Invoke-RestMethod -Headers $headers -Uri http://localhost:8080/api/app/bootstrap; $updated = $after.data.portfolioClasses | ForEach-Object { $_.items } | Where-Object { $_.id -eq $asset.id } | Select-Object -First 1; [pscustomobject]@{ assetId = $asset.id; assetName = $asset.name; beforeValue = $asset.value; afterValue = $updated.value; beforeIncome = $asset.income; afterIncome = $updated.income } | Format-List

Direct database checks
----------------------

Check whether portfolio asset values were updated:
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p -D tangent_db -e "SELECT asset_id, quantity, unit_value, current_value, annual_income, updated_at FROM portfolio_assets WHERE asset_id = 1;"

Check recent expense inserts or updates:
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p -D tangent_db -e "SELECT expense_id, expense_name, amount, spent_on, updated_at FROM buddy_expenses ORDER BY expense_id DESC LIMIT 10;"

Check recent asset updates from the portfolio page:
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p -D tangent_db -e "SELECT asset_id, asset_name, current_value, annual_income, updated_at FROM portfolio_assets ORDER BY updated_at DESC LIMIT 10;"

Check watchlist rows created from frontend actions:
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p -D tangent_db -e "SELECT wi.watchlist_item_id, w.user_id, i.symbol, wi.added_at FROM watchlist_items wi JOIN watchlists w ON w.watchlist_id = wi.watchlist_id JOIN instruments i ON i.instrument_id = wi.instrument_id ORDER BY wi.watchlist_item_id DESC LIMIT 10;"

Check table counts:
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p -D tangent_db -e "SELECT COUNT(*) AS users_count FROM users; SELECT COUNT(*) AS assets_count FROM portfolio_assets;"
